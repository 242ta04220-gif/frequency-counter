 Verilog Frequency Counter

A digital frequency counter designed using Verilog HDL.

 Overview

This project measures the frequency of an incoming digital signal using
a known reference clock.

The design counts the number of rising edges of the input signal during
a fixed measurement interval and converts the count into frequency in Hz.

Features

- Verilog HDL implementation
- Configurable reference clock frequency
- Configurable measurement gate time
- Rising-edge detection
- Input synchronization
- Frequency output in Hz
- Simulation testbench included
